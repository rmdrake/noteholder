# Note Holder Suite

A collection of lightweight, browser-based note-taking applications designed for simplicity and efficiency. This suite includes a standard note manager and a dedicated Markdown editor for structured writing.

## 🚀 Features

- **Dual Theme Support**: Easily switch between **Dark** and **Light** modes for comfortable reading in any environment.
- **Data Portability**: 
  - **Export/Import**: Save your entire collection of notes as a JSON file and restore them later or move them to another device.
  - **Save as MD**: Export individual notes directly as `.md` files.
- **Responsive Layout**: Includes a resizable sidebar for an optimized workspace.
- **Zero Installation**: Runs directly in any modern web browser.

## 📦 Applications

### 📝 Note Holder
The core application for quick note capture and organization.
- **Simple Management**: Create, edit, and delete notes with ease.
- **Organized Sidebar**: A clean list view to manage all your thoughts and snippets.
- **Clipboard Integration**: Quick "Copy" button to grab note content instantly.

### ✍️ Note Holder MD
An enhanced version built specifically for Markdown enthusiasts.
- **Live Markdown Preview**: Write in Markdown and see your formatting (headers, lists, code blocks, tables, etc.) rendered in real-time in a side-by-side split-view.
- **Rich Text Rendering**: Powered by `marked.js` to ensure high-quality, accurate Markdown rendering.
- **Structured Writing**: Perfect for drafting documentation, blog posts, or any content requiring Markdown syntax.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3 (using CSS Variables for theming), JavaScript (ES6+).
- **Markdown Rendering**: [Marked.js](https://marked.js.org/) (for the MD version).

## 🚀 Getting Started

To use these applications, simply download the files and open them in your preferred web browser:

1. Download `noteholder.html` for standard note-taking.
2. Download `noteholdermd.html` for Markdown-supported writing.
3. Open the file directly in Chrome, Firefox, Edge, or Safari.
